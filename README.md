# Sri Padmavathi Construction — Final Animated Website

This package includes the original project photographs from the supplied website ZIP.

## Included
- All 7 project images
- Correct relative image paths
- Responsive image sizing with no distortion
- Image reveal and hover zoom
- 3D card tilt
- Letter-by-letter hero text
- SVG orbit animation
- Fast scroll/parallax effects
- Three selectable themes: Warm, Sage, Slate
- Motion On/Off control
- Existing WhatsApp, booking, filters and lightbox features

## Deployment
Keep `index.html`, `styles.css`, `script.js`, and the `images` folder together in the same GitHub Pages repository.
